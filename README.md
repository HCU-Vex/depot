# HCU-Vex Depot

The official package depot for the HCU-Vex ecosystem. Contains a curated list of VPM-compatible libraries for VEXcode V5 C++.

## Installing a Package

```bash
pip install vpm-vex
cd your-vexcode-project
vpm init
vpm install package-name
```
